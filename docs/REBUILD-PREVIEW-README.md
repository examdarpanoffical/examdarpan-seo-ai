# Exam Darpan rebuild preview

This is an isolated, non-production UI prototype inspired by the information architecture of large Indian exam-update portals. It uses Exam Darpan branding and does not copy third-party source code or assets.

## Preview pages
- `public/rebuild-preview/index.html`: homepage shell and category/listing layout
- `public/rebuild-preview/style.css`: shared responsive design tokens and homepage styles
- `public/rebuild-preview/preview.js`: homepage renderer, live search and category panels
- `public/rebuild-preview/category.html`: category listing template; accepts a `category` query parameter
- `public/rebuild-preview/article.html`: article/recruitment detail template; accepts a `slug` query parameter
- `public/rebuild-preview/pages.css`: category and detail page styles
- `public/rebuild-preview/pages.js`: category/detail renderer, safe rich-content allowlist and important-link cards

## Data integration
The renderers read `/content-index.json), which is generated by `scripts/generate_static.py` from published Firestore `posts`. They do not read or write Firestore directly and do not change post status. Published article links in the preview detail templates resolve by the existing slug. Category names use the aliases already present in the static generator.

## Navigation and route checks
- Preview homepage, category and article links remain within the preview templates; the existing live quiz, mock-test and categories routes are linked as explicit Student Corner destinations.
- The three preview HTML pages retain `noindex,nofollow` and load the shared analytics script.
- A repository-tree structural check on the current branch found no missing local href/src targets across these three pages. This does not replace visual browser QA or live route testing.

## Safety
- All files are isolated under `public/rebuild-preview/`.
- Preview pages are marked `noindex,nofollow`.
- Existing homepage, article, category, admin, quiz, Firestore rules, deployment workflow, and production configuration are not modified by this prototype.
- The preview is not live until a separately approved deployment includes this branch's files.

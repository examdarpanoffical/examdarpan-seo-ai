# Exam Darpan rebuild preview

This is an isolated, non-production UI prototype inspired by the information architecture of large Indian exam-update portals. It uses Exam Darpan branding and does not copy third-party source code or assets.

## Files
- `index.html`: preview shell and category/listing layout
- `style.css`: responsive styles for desktop, tablet and mobile
- `preview.js`: read-only renderer for the existing generated public content index

## Data integration
The renderer reads `/content-index.json`, which is already generated by `scripts/generate_static.py` from published Firestore `posts`. It does not read or write Firestore directly and does not change post status. Published article links use their existing clean slugs. Legacy category aliases are normalized to the same category names used by the static generator.

## Safety
- This folder is isolated under `public/rebuild-preview/`.
- The preview page is marked `noindex,nofollow`.
- No existing homepage, article, category, admin, quiz, Firestore rule, deployment workflow, or production configuration is modified by this prototype.
- The preview is not live until a separately approved deployment includes this branch's files.
